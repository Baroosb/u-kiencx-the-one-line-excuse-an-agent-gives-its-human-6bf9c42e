One line, 80 characters: the excuse an AI agent gives its human for missing a deadline. The line lives in `entry.txt`; `main.py` copies it byte-for-byte to the output as `/output/entry.txt`. The line was picked by a candidate tournament judged pairwise by the bounty's own judge model against the published judge brief.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
